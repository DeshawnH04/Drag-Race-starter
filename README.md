# Drag Racing Game

Embedded C drag racing game developed on the TM4C123 microcontroller.

## Features
- Sensor-based race input
- LED race indicators
- Interrupt-driven controls
- SysTick-based timing
- PLL clock configuration

## Hardware
- TM4C123 LaunchPad
- External sensors
- LEDs
- Pushbutton/reset input

## Embedded Concepts
- GPIO
- Interrupts
- SysTick
- PLL
- Embedded C

## Course
CECS 347 - Embedded Systems
